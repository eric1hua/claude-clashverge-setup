# Agent 安装提示词

将下面整个代码块复制给能够访问目标 Mac 终端的 Agent。默认沿用当前订阅和 `JMS` 组当前的物理节点；如果要管理其他订阅或来源组，在提示词末尾补充名称即可，不要粘贴订阅 URL、密码或 Claude token。

```text
请在本机安装并验收 https://github.com/eric1hua/claude-clashverge-setup 的 Claude 路由扩展。我授权你在该项目范围内完成源码审查、依赖准备、备份、部署、Clash Verge 正常重载和必要验证；不要停在给我命令或建议。

执行要求：
1. clone 仓库到合适的项目目录；如果已有 checkout，先检查来源和未提交修改，不覆盖我的文件。读取 AGENTS.md、README.md、docs/operations/runbook.md、安装脚本和部署实现。
2. 先只读检查 macOS、Clash Verge Rev、Mihomo、Python、Node.js、当前活动订阅、来源代理组和该组所选物理节点。当前适配范围为 Clash Verge Rev 2.5.2 / Mihomo 1.19.29；其他版本不要通过删版本检查强行安装。不要输出订阅 URL、节点密码、Claude token、Cookie 或完整运行配置。
3. 默认只管理当前订阅，来源组默认 JMS，沿用当前实际节点。不要自动挑其他国家、其他节点或另一个订阅。检查现有订阅脚本是否包含自定义逻辑；对于未知脚本，先阅读、说明冲突及替换会失去的功能，再决定是否需要用户选择。不得为了通过检查直接加 --adopt-existing-script。
4. 使用 ./install.sh --dry-run 准备私有依赖与候选并执行核心校验，审阅计划。不要运行 curl | bash，不使用 sudo，不自动安装 Homebrew，不修改系统 Python、TUN、系统代理、全局 shell 配置或证书校验。依赖缺失时说明具体缺项。
5. 在上述范围和检查通过后，执行 ./install.sh --yes；我已授权常规安装步骤，无需重复让我确认。必要的订阅/来源组/节点参数在 dry-run 和实际安装时保持一致。未知脚本的功能取舍及超出范围的操作仍须解释具体原因后处理，遵守运行环境审批。
6. 确保安装前备份成功、核心校验通过，随后经 Clash Verge 正常退出并重开完成正式重生成。重载会暂时影响所有经过该代理的连接；不得强制杀进程，也不得把仅写文件或调用 Mihomo reload 当成完整生命周期验收。
7. 运行项目验收工具，检查规则模式、Claude 组准确节点、所选域名规则、DNS 策略和持久文件。匿名网络检查与账号会话分开报告；不要读取或复用我的 Claude 凭据，不替我登录、连续重试登录或消耗模型额度。已有自定义服务的兼容性只在取得实际证据后确认。
8. 若失败，保留私有备份和必要的脱敏错误，按操作手册处理；不要覆盖安装后出现的并发修改。不要把 .local、备份、索引、私有诊断或机器配置推送到 GitHub。
9. 最终用中文报告：实际改了哪些订阅扩展、节点选择是否保持、备份与回滚位置、哪些静态/核心/运行/网络检查实际通过、哪些尚未验证。给出本地文件链接。网络配置不能保证不封号，也不能证明地区政策资格；不要将它描述为反检测或账号安全保证。
```

安装结束后，Desktop、TUI 和网页的真实工作验收仍需要用户的正常会话。`--yes` 仅跳过安装器的交互确认，不会绕过未知脚本、版本、核心校验或文件漂移保护。
